API Documentation

Use the {{WEBSITE_NAME}} API to get phone numbers, receive SMS codes, and manage activations from your application.

1. Authentication

All API requests (except public reference data) require an API key. Generate one in the section below when logged in.

Send your API key in one of two ways:

  • Header: X-API-Key: your_api_key_here
  • Header: Authorization: Bearer your_api_key_here

Example:

curl -H "X-API-Key: YOUR_KEY" "{{APP_URL}}/api/v1/balance"

3. Base URL

Authenticated API base:

{{APP_URL}}/api/v1

Replace with your actual domain if different (from APP_URL in .env).

4. Authenticated endpoints (require API key)

MethodPathDescription
GET/balanceGet your account balance (USD).
POST/get-numberOrder a phone number. Body: service, country (default: usv), operator, rent (boolean).
GET/activationsList your activations (phone numbers ordered).
GET/activation/:id/statusGet status and SMS code(s) for an activation. Poll until status is got_sms.
POST/activation/:id/statusUpdate status. Body: action = send (request more SMS), end (cancel, refund), bad (number bad, refund).
POST/activation/:id/cancelCancel activation and refund (only if SMS not received yet).
POST/activation/:id/bannedReport number as banned/bad and refund (only if SMS not received yet).
POST/activation/:id/reuseReuse / extend number after expiry (same price; number waits for SMS again).
POST/activation/:id/prolongSame as /reuse — extend number after expiry.

5. Public endpoints (no API key)

Use these to get services, countries, and operators. Base URL: /api (no /v1). All icon fields are full URLs (use APP_URL from .env).

MethodPathDescription
GET/api/servicesAll services with code, name, icon. Optional: ?country=usv and &operator= to return only services available in that country/operator (each item includes count, priceUsd).
GET/api/countriesCountries with countryCode, countryName, operatorList, count, icon (full URL).
GET/api/operatorsOperators by country; each country and operator has icon (full URL).
GET/api/price/:servicePrice for a service. Query: country, operator. Returns count, priceUsd.

7. Example flow: get number and wait for SMS

Step 1 — Order a number

POST {{APP_URL}}/api/v1/get-number
Content-Type: application/json
X-API-Key: YOUR_KEY

{
  "service": "wa",
  "country": "usv",
  "operator": "",
  "rent": false
}

Response:

{
  "activation": {
    "id": 123,
    "phone": "+1234567890",
    "service": "wa",
    "service_name": "WhatsApp",
    "price_usd": 0.15,
    "status": "waiting",
    "created_at": "2025-03-07T12:00:00.000Z"
  }
}

Step 2 — Poll for SMS

GET {{APP_URL}}/api/v1/activation/123/status
X-API-Key: YOUR_KEY

When SMS is received:

{
  "status": "got_sms",
  "sms_code": "123456",
  "sms_codes": ["123456"]
